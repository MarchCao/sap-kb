## 一句话理解

**物料主数据（Material Master）是 SAP 里对"东西"的统一描述**：一个物料编码背后，挂着采购、库存、生产、销售、财务需要的所有属性。它按"视图"组织、按"组织级别"维护，是 MM 所有业务的地基——主数据错了，后面单据全错。

::: tip
实战提示：把物料主数据想象成"一份档案"，不同部门填写不同页：采购填采购视图、仓库填仓储视图、财务填会计视图。MM01 创建时选视图 = 决定哪些部门"填写档案"。
:::

## 核心概念

### 视图（View）

| 视图 | 维护内容 | 主要使用方 |
|------|----------|------------|
| 基本数据 | 描述、基本计量单位、物料组 | 全员 |
| 采购 | 采购组、计划交货时间、自动 PO 标识 | 采购 |
| MRP | MRP 类型、批量、计划策略 | 计划 |
| 仓储/库存管理 | 库存地点相关、批次管理标识 | 仓库 |
| 会计 | 价格控制（S/V）、移动平均价/标准价 | 财务 |
| 成本 | 成本核算相关 | CO |

### 组织级别

- **Client 层**：基本数据视图，全集团共用。
- **工厂层**：采购、MRP、仓储、会计视图，每个工厂可不同。
- 新工厂上线时，物料需要**扩展（Extend）**到新工厂，即为新工厂维护对应视图。

### 物料类型（Material Type）

物料类型决定：编号是内部给号还是外部给号、允许哪些视图、默认价格控制、允许哪些移动类型。

| 物料类型 | 说明 | 典型价格控制 |
|----------|------|--------------|
| ROH（原材料） | 采购入库、生产领用 | 移动平均价（V） |
| HALB（半成品） | 自制+外购均可 | 标准价（S）或移动平均价 |
| FERT（产成品） | 销售给客户 | 标准价（S） |
| HAWA（贸易商品） | 买来直接卖 | 移动平均价（V） |
| DIEN（服务） | 无实物、无库存管理 | — |
| NLAG（非库存物料） | 低值易耗品等 | — |

::: warning
常见坑：**物料类型的价格控制一旦有库存移动就很难改**。项目初期物料类型和价格控制（V/S）的设计要和财务对齐：原材料用移动平均价、产成品用标准价是常见做法，但必须在蓝图阶段定死，上线后改等于推倒重来。
:::

## 关键字段说明

| 字段 | 视图 | 说明 |
|------|------|------|
| 基本计量单位（Base UoM） | 基本 | 库存数量的基准单位，创建后极难修改 |
| 物料组（Material Group） | 基本 | 报表、采购分组的维度，设计要稳定 |
| 采购组（Purchasing Group） | 采购 | 负责该物料的采购员/组 |
| 计划交货时间 | 采购/MRP | 供应商交货提前期，影响 MRP 和 PO 交货日期 |
| MRP 类型 | MRP | 如 PD（MRP）、ND（不参与计划）、VB（手工重订货点） |
| 批量大小 | MRP | 如 EX（按需批量）、FX（固定批量） |
| 价格控制 | 会计 | V=移动平均价，S=标准价 |
| 批次管理标识 | 仓储 | 启用后收发货必须指定批次 |

## 实战操作要点

**MM01 创建**：输入物料编码（或内部给号时留空）→ 选择物料类型 → 选择视图 → 选择组织级别（工厂/库存地点）→ 逐视图维护字段 → 保存。

**MM02 修改**：注意字段的"可修改性"受物料状态控制——已有库存/采购订单的物料，很多字段会被锁。

**MM03 显示**：排错时的第一站，先看主数据再看单据。

```checklist
- [ ] 物料类型与价格控制是否符合财务要求
- [ ] 基本计量单位是否正确（创建后几乎无法改）
- [ ] 需要的工厂是否都已扩展视图
- [ ] 采购视图的采购组是否维护
- [ ] MRP 视图是否按计划员要求维护
- [ ] 会计视图价格控制与物料类型一致
```

::: tip
实战提示：批量创建/修改物料用 `MM17`（批量维护）或 LSMW/BAPI，**不要手工一个个敲**。上线前主数据收集模板里，组织级别列（工厂清单）一定要和蓝图冻结的企业结构一致。
:::

## 常见问题

### Q：物料建错了组织级别怎么办？
A：用 MM01 以"扩展"方式补建缺失的组织级别视图即可，不需要删了重建。但如果基本计量单位、物料类型错了，那就麻烦得多——基本计量单位有业务数据后几乎无法改，只能新建物料并做替代。

### Q：为什么 MM02 里有些字段是灰的改不了？
A：通常两个原因：① 字段状态组配置为"显示"；② 物料已有库存、未清采购订单或会计凭证，系统为保护数据一致性锁定。先查单据，再找配置。

### Q：S/4HANA 里物料主数据有什么变化？
A：核心概念不变。变化主要在：① 必须启用物料分类账（影响会计视图）；② 长物料号（40 字符）成为可选项；③ Fiori 的"管理产品主数据"应用逐步替代部分 GUI 操作。

## 实战经验

- 主数据质量 = 项目质量。**脏主数据是上线后 80% 异常的根因**：重复物料、计量单位混乱、价格控制混用，每一个都会在业务中爆发。
- 给业务部门的主数据收集模板，字段说明要用业务语言写（"计划交货时间：供应商从接单到送货要几天"），不要直接贴 SAP 字段名，否则收回来全是空的。
- 物料描述建议定命名规范（如"品牌+规格+型号"），方便搜索和去重。没有规范的物料库，三年后就是垃圾场。
